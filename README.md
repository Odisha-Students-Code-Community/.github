# OSCC .github — Master Organization Governance ❤️

This repository contains organization-level default files, community health files, and the official organization profile for the **Odisha Students Code Community (OSCC)**.

---

## 📁 Repository Overview
- `profile/README.md`: The public profile landing page displayed on [github.com/Odisha-Students-Code-Community](https://github.com/Odisha-Students-Code-Community).
- `CONTRIBUTING.md`: Default organization-wide contribution guidelines.
- `CODE_OF_CONDUCT.md`: Community standards and harassment policy.
- `SUPPORT.md`: Community support channels and reporting guidelines.
